# RVSoC8787 specification

A 32-bit RISC-V microcontroller: the lowRISC Ibex core (RV32IMC), 4 KiB of instruction SRAM, 4 KiB of data
SRAM, a serial program loader, eight GPIO outputs and a scan chain, in a 25-pad ring on IHP SG13G2. It runs at
20 ns, 50 MHz. Pins, bring-up and results are in Datasheet.md.
